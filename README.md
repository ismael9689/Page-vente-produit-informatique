# 💻 TechStore - Site de vente de matériel informatique

## 📌 Description

Projet réalisé en équipe consistant à créer un site web de vente de matériel informatique.

L'objectif était de concevoir une plateforme permettant aux utilisateurs de découvrir différents produits informatiques (ordinateurs, composants, accessoires...) à travers une interface claire et intuitive.

Ce projet nous a permis de mettre en pratique les bases du développement web et le travail collaboratif en équipe.

---

## 🚀 Fonctionnalités

✅ Page d'accueil présentant le site  
✅ Page de vente des produits  
✅ Présentation des différents articles informatiques  
✅ Page "À propos"  
✅ Page d'inscription utilisateur  
✅ Interface adaptée à la navigation utilisateur  

---

- HTML5

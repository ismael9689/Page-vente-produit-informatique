# 💻 TechStore - Computer Hardware Store Website

## 📌 Description

A team project: a website that sells computer hardware.

The goal was to build a platform where users can discover different computer products (computers, components, accessories...) through a clear and easy interface.

This project helped us practice the basics of web development and teamwork.

---

## 🚀 Features

- ✅ Home page that presents the website
- ✅ Product sales page
- ✅ Presentation of the computer products
- ✅ "About" page
- ✅ User sign-up page
- ✅ Easy-to-use navigation

---

## 🛠️ Built with

- HTML5
- CSS3
- JavaScript

---

## 📂 Project structure

```text
Page_accueil.html        home page
Page_Vente.html          product sales page
Page_apropos.html        "About" page
Page_inscription.html    sign-up page
Style_CSS_triplOS.css    styles
Style_Java_triplOS.js    JavaScript
```
